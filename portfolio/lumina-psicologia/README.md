# Lúmina Psicologia 🌿

Site responsivo para uma **profissional de psicologia fictícia**, criado como projeto demonstrativo de portfólio.

> **Importante:** Lúmina Psicologia, Dra. Helena Duarte, CRP, valores, endereço e demais informações apresentadas no projeto são fictícios. O site não presta atendimento psicológico e não deve ser confundido com um serviço real.

## Objetivo

Demonstrar uma solução digital para psicólogos e profissionais de atendimento individual, equilibrando apresentação profissional, credibilidade, acolhimento visual, clareza sobre os formatos de atendimento e geração de contato via WhatsApp.

## Funcionalidades

- layout responsivo para desktop, tablet e celular;
- menu mobile;
- hero com CTA;
- seção institucional;
- cards de formatos de atendimento;
- passo a passo do processo;
- FAQ interativo;
- formulário de primeiro contato;
- geração automática de mensagem para WhatsApp;
- botão para copiar a mensagem;
- nenhum dado enviado ou armazenado;
- animações com `IntersectionObserver`;
- suporte a `prefers-reduced-motion`;
- avisos explícitos de conteúdo fictício.

## Tecnologias

- HTML5
- CSS3
- JavaScript Vanilla
- Google Fonts

## Privacidade e UX

O formulário evita solicitar diagnóstico, sintomas detalhados ou outras informações clínicas sensíveis. Ele coleta apenas o necessário para iniciar um contato e apenas prepara uma mensagem no dispositivo do visitante.

Também foram evitadas promessas de resultado terapêutico e linguagem apelativa.

## Personalização

No arquivo `script.js`, altere `WHATSAPP_NUMBER` para o telefone real no formato DDI + DDD + número.

Em um projeto real, substitua nome, CRP, formação, abordagem, modalidades, valores, localização e canais de contato por informações profissionais verificáveis.
